# 更新履歴

Bingle の変更点です。新しいものから順に並んでいます。Bingle Core（サーバー、エンジン、ウェブクライアント）と各ゲームにはそれぞれバージョンがあり、各項目でどれが変わったかを示しています。0.124.0 より前の項目は英語のみです。

- サーバーがチャット用に独自の翻訳サービスを接続できるようになりました
