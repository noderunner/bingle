# Nouveautés

Ce qui a changé dans Bingle, du plus récent au plus ancien. Bingle Core (le serveur, le moteur et le client web) et chaque jeu ont leur propre version, et chaque entrée dit lesquels ont changé. Les entrées antérieures à la 0.124.0 ne sont qu’en anglais.

## 0.126.1 - 2026-11-23

### Bingle Core 0.126.1
- Les nouveautés de la fenêtre d’aide sont dans votre langue

## 0.126.0 - 2026-11-23

### Bingle Core 0.126.0
- Les e-mails et les invitations d’agenda sont dans votre langue

## 0.125.6 - 2026-11-23

### Bingle Core 0.125.6
- La page d’administration et les séries d’entraînement sont traduites

## 0.125.5 - 2026-11-23

### Bingle Core 0.125.5
- Les pages du compte, la page d’un joueur et les pages des liens des e-mails sont traduites

## 0.125.4 - 2026-11-23

### Bingle Core 0.125.4
- Les plateaux, les cartes, les jeux de cartes et la réussite sont traduits

## 0.125.3 - 2026-11-23

### Bingle Core 0.125.3
- La barre des coups, l’historique, les options et la carte du tutoriel d’une partie sont traduits

## 0.125.2 - 2026-11-23

### Bingle Core 0.125.2
- Le tour, les joueurs, les résultats et la barre d’état d’une partie sont traduits

## 0.125.1 - 2026-11-22

### Bingle Core 0.125.1
- Le salon, le chat (avec les noms des emoji) et la fenêtre des règles d’une partie sont traduits

## 0.125.0 - 2026-11-22

### Bingle Core 0.125.0
- Un coup que vous allez jouer indique les pièces qu’il prendra, pour que les applis les montrent d’abord (API 1.10.0)

### Fist 0.1.4
- Un coup enregistre les pièces qu’il a prises

## 0.124.4 - 2026-11-22

### Bingle Core 0.124.4
- La visite de bienvenue est traduite

## 0.124.3 - 2026-11-22

### Bingle Core 0.124.3
- Analyse, Classement, Tournois, Chat général et les badges sont traduits

## 0.124.2 - 2026-11-22

### Bingle Core 0.124.2
- La page d’accueil est traduite : les jeux, créer une partie, les tutoriels, les puzzles et les anecdotes

## 0.124.1 - 2026-11-22

### Bingle Core 0.124.1
- La barre du haut et ses fenêtres (parties, rejoindre, amis, appels, aide) sont traduites

## 0.124.0 - 2026-11-22

### Bingle Core 0.124.0
- Un réglage de langue dans votre profil : dix langues, l’arabe de droite à gauche ; pour l’instant le profil est traduit (API 1.9.0)
