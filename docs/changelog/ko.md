# 변경 기록

Bingle에서 바뀐 것을 최신순으로 적었습니다. Bingle Core(서버, 엔진, 웹 클라이언트)와 각 게임에는 저마다 버전이 있으며, 각 항목에 무엇이 바뀌었는지 적혀 있습니다. 0.124.0 이전 항목은 영어로만 제공됩니다.

## 0.140.0 - 2026-11-27

### Bingle Core 0.140.0
- Reversi 대국과 레이팅이 이제 Othello로 옮겨졌습니다

### Othello 0.4.0
- 실제 규칙에 맞게 Othello로 이름을 바꾸고 고안자를 Goro Hasegawa로 표기했습니다

## 0.139.0 - 2026-11-26

### Bingle Core 0.139.0
- 서버가 로고의 메뉴에서 3D 클라이언트를 제공할 수 있으며, 사용자 본인으로 연결해 주는 설정 파일도 함께 제공합니다 (API 1.18.0)

## 0.138.0 - 2026-11-25

### Bingle Core 0.138.0
- 설치 팩에 3D 클라이언트 등 다른 클라이언트용 게임 모양을 담을 수 있습니다 (API 1.17.0)
