# 변경 기록

Bingle에서 바뀐 것을 최신순으로 적었습니다. Bingle Core(서버, 엔진, 웹 클라이언트)와 각 게임에는 저마다 버전이 있으며, 각 항목에 무엇이 바뀌었는지 적혀 있습니다. 0.124.0 이전 항목은 영어로만 제공됩니다.

## 0.155.0 - 2026-11-28

### Bingle Core 0.155.0
- 웹 페이지에서 Bingle3D로 게임에 참가하거나 관전합니다 (API 1.30.0)

## 0.154.0 - 2026-11-28

### Bingle Core 0.154.0
- 봇 배치가 실행되는 동안에도 사람이 있는 게임은 빠르게 유지됩니다

## 0.153.2 - 2026-11-28

### Bingle Core 0.153.2
- API로 시작한 배치가 지정한 이름을 유지합니다

## 0.153.1 - 2026-11-28

### Bingle Core 0.153.1
- MCP에서 배치 시작과 취소, 게임 만들기와 가져오기, 참가, 채팅, 토너먼트 체크인에 이제 API와 같은 권한이 필요합니다

## 0.153.0 - 2026-11-28

### Bingle Core 0.153.0
- 봇 배치에 제한이 생겼고, 시간 제한에 도달한 배치는 멈추고 그 사실을 표시합니다 (API 1.28.0)

## 0.152.0 - 2026-11-28

### Bingle Core 0.152.0
- 봇마다 게임별 레이팅이 생겼고 매일 밤 대국으로 갱신됩니다: 레이팅 탭과 봇 안내에서 볼 수 있습니다 (API 1.27.0)

## 0.151.2 - 2026-11-28

### Bingle Core 0.151.2
- 두 번째 자리를 맡는 튜토리얼(체스의 "게임이 끝나는 방법" 등)을 끝까지 진행할 수 있습니다

## 0.151.1 - 2026-11-27

### Chess 0.3.0

## 0.151.0 - 2026-11-27
