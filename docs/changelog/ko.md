# 변경 기록

Bingle에서 바뀐 것을 최신순으로 적었습니다. Bingle Core(서버, 엔진, 웹 클라이언트)와 각 게임에는 저마다 버전이 있으며, 각 항목에 무엇이 바뀌었는지 적혀 있습니다. 0.124.0 이전 항목은 영어로만 제공됩니다.

## 0.132.1 - 2026-11-23

### Bingle Core 0.132.1
- 한 판으로 그려지는 두 판 사이에 구분선이 생겼습니다

### Chess 0.2.1
- 앨리스 체스: 수는 자기 판에서 두므로, 잡을 때는 잡을 기물을 클릭합니다

## 0.132.0 - 2026-11-23

### Bingle Core 0.132.0
- 새 체스 변형

### Chess 0.2.0
- 체스960, 크레이지하우스, 안티체스, 아토믹 체스, 앨리스 체스

## 0.131.0 - 2026-11-23

### Bingle Core 0.131.0
- 새 게임: 체스

### Chess 0.1.0 — a new game
- 캐슬링, 앙파상, 프로모션과 모든 무승부 규칙
