# 更新日志

Bingle 的变化，最新的在前。Bingle Core（服务器、引擎和网页客户端）和每个游戏都有各自的版本，每一条都会说明是哪个变了。0.124.0 之前的条目只有英文。

## 0.132.1 - 2026-11-23

### Bingle Core 0.132.1
- 绘成一块的两个棋盘之间加了分隔线

### Chess 0.2.1
- 爱丽丝国际象棋：走法在本棋盘上进行，吃子时点击被吃的棋子

## 0.132.0 - 2026-11-23

### Bingle Core 0.132.0
- 新的国际象棋变体

### Chess 0.2.0
