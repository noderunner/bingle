# Список изменений

Что изменилось в Bingle, сначала самое новое. У Bingle Core (сервера, движка и веб-клиента) и у каждой игры своя версия, и в каждой записи сказано, что изменилось. Записи до 0.124.0 есть только на английском.

## 0.143.0 - 2026-11-27

### Bingle Core 0.143.0
- Для авторов игр: в веб-файле то, чем рисуются оттенок, значок, масть или рубашка карты, называется paint (API 1.20.3)

## 0.142.2 - 2026-11-27

### Bingle Core 0.142.2
- Слово «color» теперь пишется одинаково во всём интерфейсе (API 1.20.2)

### Amazons 0.3.2, Ataxx 0.3.2, Blooms 0.6.3, Chess 0.2.3, Fendo 0.1.4, Fist 0.1.5, Go 0.3.2, Gomoku 0.3.2, Havannah 0.3.3, Hex 0.3.2, Meridians 0.1.5, Othello 0.4.1, Pente 0.3.2, Solitaire 0.4.1, Tak 0.1.2 and Yavalath 0.3.2
- В руководствах слово «color» пишется по-американски

## 0.142.1 - 2026-11-27

### Bingle Core 0.142.1
- Звонок, пришедший, пока ваше соединение прерывалось, теперь всё равно звонит (API 1.20.1)

## 0.142.0 - 2026-11-27

### Bingle Core 0.142.0

## 0.141.0 - 2026-11-27
