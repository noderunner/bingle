# Список изменений

Что изменилось в Bingle, сначала самое новое. У Bingle Core (сервера, движка и веб-клиента) и у каждой игры своя версия, и в каждой записи сказано, что изменилось. Записи до 0.124.0 есть только на английском.

## 0.137.0 - 2026-11-25

### Bingle Core 0.137.0
- Боты играют в игры из установочных пакетов быстрее и сильнее

## 0.136.0 - 2026-11-25

### Bingle Core 0.136.0
- Игры своими словами сообщают, как они закончились (API 1.16.0)

## 0.135.1 - 2026-11-25

### Bingle Core 0.135.1
- Серые фишки рисуются серыми

## 0.135.0 - 2026-11-25

### Bingle Core 0.135.0
- Серверы могут предлагать игры из установочных пакетов

## 0.134.0 - 2026-11-25

### Bingle Core 0.134.0
- Новый набор карт «Расширенная классика»: четыре классические масти, а также четырёхлистники, луны, стрелы и песочные часы (API 1.15.0)

## 0.133.0 - 2026-11-25

### Bingle Core 0.133.0
- Игры на двух досках показывают каждую доску отдельно

### Chess 0.2.2
- Шахматы Алисы: две доски нарисованы как две доски, рядом друг с другом

## 0.132.2 - 2026-11-24

### Bingle Core 0.132.2
- Изменений вне Fendo нет

### Fendo 0.1.3
- Партия заканчивается, как только в открытой области остаются фигуры только одного игрока: эта область достаётся ему

## 0.132.1 - 2026-11-23

### Bingle Core 0.132.1

### Chess 0.2.1

- Шахматы-960: король рядом с полем рокировки может пойти туда, а не только рокироваться
