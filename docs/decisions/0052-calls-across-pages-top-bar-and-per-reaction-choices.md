# 0052. A voice call that outlives the page, the top bar of a game, and a choice for each reaction

Status: accepted (2026-10-26)

## Context

The player asked for four things: the top bar of a game should carry the active games (with who is waiting for them), joining and the profile, to see at a glance that it is their turn in another game and to switch; a voice call should stay up when they open another game or the main page, with a small button in the top bar saying so; and in Cthulhu Wars the Reactions boxes of the options window should be separate for each reaction (the Crawling Chaos' Madness and the Unspeakable Oath), with Madness asking about everything by default.

## Decision

- **Top bar** (`topbar.js`, now installed by `game.js` too): the same three icons as the main page, after *Rules* and *Options*. On a game page it leaves the tab title and icon to the game (`manageTitle: false`).
- **A call is not a page's.** `voice.js` already kept the call in module state; the pieces that tied it to the page were the page's WebSocket (which carried the `rtc` messages) and the document itself. The call now opens a WebSocket of its own, `/ws/{code}?only=voice` (the server sends it only `voice` and `rtc` events, subscribes to the seat's messages *before* it says `joined`, and does not count it as the player looking at the game), and opens it before announcing itself. The page's socket no longer carries `rtc`.
- **Soft navigation** (`nav.js`): while a call is up (`setKeepAlive`), a click on a link to `/`, `/game/{code}` or `/profile` (and `navigate()` for the redirects of the pages) fetches the page and swaps the body instead of loading it, then runs the new page's script with `import("…?nav=n")` — a new instance of that one module; the modules it imports (and the call) are the ones already loaded. With no call, nothing changes: links load pages. The alternatives were a separate window for the call (a popup, bad on a phone) or making every page an app (a rewrite); this keeps the pages as they are and only changes how they are left. What the page made — listeners on the window and document, timers, `WebSocket`s, media-query listeners — is noted while it lives (the browser functions are wrapped once, `untracked()` opts out for what must outlive the page) and undone when it is left; the modules that keep state of a page (`chat.js`, `render.js`, `tooltip.js`, the call's view of the game on screen) reset through `onNavigate`; the SVG definitions and the call's `<audio>` carry `data-persist` and stay. `popstate` follows the history when the path changes; a failed soft navigation falls back to loading the page.
- **The button of the call** (`#voice-chip`) is in the top bar of every page while a call is up (with the room code when the call is in a game other than the one on screen), and opens `#voice-pop`: *Go to the game*, *Mute*, *Deafen*, *Leave*. The voice card of another game says where the call is and can move it (*Talk in this game instead*). One call per tab; reloading still leaves it.
- **Reactions** (`session/reactions.go`, `store.ReactionPrefs.Abilities`): the choice (`targeted`, `ask_all`, `ask_seats`) is kept per ability id as well as for all of them; `PUT /reactions` takes `ability` (unknown ones are `400`), and without it changes every reaction (the general fields and each one set apart, field by field). `GET` returns `choices` by ability id. A reaction that is `ask_always` (`state.ReactionAbility.AskAlways`; Madness) starts with `targeted` and `ask_all` on while nothing was saved; once the player has saved a choice for the game their choice stands. The seat list of such a default is empty and the seat boxes are drawn ticked and disabled while *any action* is on, so unticking it leaves a clean slate. The options window has a block per reaction (`.reaction-ability`, ids `ask-<id>-…`) and the shortcuts under a question change that reaction's choice only. MCP `set_reactions` takes `ability`.

## Interpretations

"Check all boxes by default" for Madness is *when I'm targeted* and *after any other player's action* (which implies every player's). Existing games where the player had already saved a choice keep it for Madness too. Walk Between Worlds and the Unspeakable Oath keep their old default (targeted only; Walk is always asked while Shamblers wait). The soft navigation is only used while a call is up, so a mistake in it cannot affect anyone who is not in a call.
