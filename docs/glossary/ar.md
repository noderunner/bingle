# Glossary: العربية

صيغة الأمر للمخاطَب. «المباراة» مباراة تُلعب، و«اللعبة» اللعبة نفسها.

Each word is as the interface shows it in the term's key ([en.md](en.md)). Where it shares a word with another
term, its note says `Same word as` that term.
